# 🎮 MixMaster NPC Reader

![Version](https://img.shields.io/badge/version-2.2-blue)
![Python](https://img.shields.io/badge/python-3.10+-green)
![License](https://img.shields.io/badge/license-MIT-yellow)

Sistema especializado para leitura e análise de arquivos .lua de NPCs do MixMaster Online.

## 🐋 Homenagem à Baleia Azul

> "A beleza do oceano está em suas criaturas, assim como a beleza do código está em sua simplicidade e funcionalidade."

## ✨ Funcionalidades

- 📁 Leitura de arquivos .lua
- 🔍 Detecção inteligente de funções
- 📊 Estatísticas detalhadas
- 🎯 Extração de Quest IDs
- 📦 Exportação para JSON
- 🎨 Interface moderna com CustomTkinter

## 📥 Download

[Baixar a versão mais recente](https://github.com/AnderSU-TCM/NPC_READER/releases)

## 🚀 Como Usar

1. Baixe o arquivo `.exe`
2. Execute o programa
3. Clique em "Abrir Pasta" e selecione a pasta com seus arquivos .lua
4. Navegue pelos arquivos e veja as informações

## ⌨️ Atalhos

- `Ctrl+O` - Abrir pasta
- `Ctrl+S` - Salvar análise
- `Ctrl+F` - Buscar no arquivo
- `Ctrl+Q` - Sair

## 🛠️ Tecnologias

- Python 3.10+
- CustomTkinter
- Regex
- JSON
